# Contributing to Guardian Watch

Thanks for your interest in improving Guardian Watch.

## Local setup

1. Clone the repo.
2. Create a virtual environment.
3. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

4. Run the app:

```bash
streamlit run guardian_watch/ui/streamlit_app.py
```

## Pull requests

- Keep changes focused and well described.
- Include a short summary of the problem, fix, and validation.
- Test the app locally before submitting.

## Code of conduct

Please be respectful, constructive, and safety-focused in all contributions.
